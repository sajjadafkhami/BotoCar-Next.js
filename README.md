# 🚗 BotoCar

**BotoCar** is a sleek car marketplace web app built with **Next.js**, where users can explore, search, and view detailed information about cars.

---

## ✨ Features

### 🔎 Price-Based Search
Users can filter cars by entering a **minimum** and **maximum** price range, narrowing down the results to fit their budget.

### 🚘 Car Type Filters
Easily browse cars by category:
- 🚗 **Sedan**
- 🚙 **SUV**
- 🚐 **Hatchback**
- 🏎️ **Sport Car**

### 📃 View All Cars
Click the **"See All Cars"** button to display the full collection of listed vehicles.

### 📦 Car Cards
Each car is displayed as a card that includes:
- A featured image
- Car model name
- Brief information

Clicking on a card navigates to the **detailed view** of the selected car.

### 🧾 Car Detail Page
Includes the following information:
- **Company** (e.g., Volkswagen)
- **Model** (e.g., T-Roc TSI)
- **Kilometers driven**
- **Year of first registration**
- **Location**
- **Extra information** with equipment highlights and specs (e.g., LED headlights, climate control, infotainment system)

---

## 🛠 Tech Stack

- **Framework:** Next.js
- **Language:** JavaScript 
- **Styling:** CSS Modules 
- **Routing:** File-based routing via Next.js
